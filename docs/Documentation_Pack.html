Project Proposal

Scope, timeline and milestones

Prepared for:MR UPGRADE — Lubega ShananPrepared by:Kasozi Hafizu
Proposal date:8th November 2026Valid until:22nd November 2026

1. Executive Summary

MR UPGRADE needed a professional online presence to move their smartphone and installment-plan business beyond WhatsApp-only sales. The solution is a fully functional e-commerce website built with PHP and MySQL, hosted live at mrupgrade.mmuhub.com. Customers can browse 66+ products across 14 categories, place orders, pay via MTN MoMo or Airtel Money through Pesapal, and manage installment plans online. The admin controls everything through a secure dashboard. The result is a faster, scalable sales process that works 24/7 without manual intervention.

2. Proposed Solution

Platform / StackPlain PHP + MySQL
Why this platformLightweight, fast, full control, no licensing costs, runs on any cPanel host
Site structureHome, Shop, Product Detail, Cart, Checkout, Orders, Installment Plan, About, Store, Contact
Business featureE-commerce store with installment plan management and mobile money payments
Hosting & domaincPanel hosting; Domain: mrupgrade.mmuhub.com; SSL certificate (HTTPS)

3. Scope of Work

  1. Branded, responsive multi-page website (14 categories, 66+ products, real client content)
  2. User registration, login, cart, checkout, order tracking
  3. Installment plan system (40% deposit, 10/12/16 weeks, weekly payment tracking)
  4. Pesapal payment integration (MTN MoMo + Airtel Money — sandbox → live)
  5. Admin panel — products, orders, customers, messages, installments, profile
  6. Africa's Talking SMS reply system from admin messages panel
  7. HTTPS, security hardening (CSRF, rate limiting, prepared statements, .htaccess)
  8. SEO (meta tags, Open Graph, JSON-LD structured data, sitemap, robots.txt)
  9. Admin guide, training documentation, support package

View and update ordersAdmin → Orders → click any order → scroll to Update Status → select status → Update

Reply to customer messagesAdmin → Messages → click message → Reply Via Email / WhatsApp / SMS
